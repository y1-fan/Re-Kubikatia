Re-Kubikatia

Import from Kubikat: paste a search-results URL, or one item link per line. This plugin uses the SRU interface only, one request at a time, and writes records straight into a new Zotero collection.

Rate limits: 1 request at a time · 10 seconds between requests · maximum 50 items per import. Do not run repeated large imports or try to bypass these limits. Please respect Kubikat's robots.txt and terms of use.
